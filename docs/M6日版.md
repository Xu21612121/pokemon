# M6 Storm Emeralda

用户提供PokeInvest保存HTML及图片目录，113张图片按网页卡号匹配，禁止按下载文件名序号猜测卡号。报价为网页美元快照，以用户已同意的1美元=7.20元固定汇率换算，非实时行情；整理日期2026-10-28。价格表见 `prices/M6日版-美元人民币价格表.csv`。

包装图片及单包价格也来自附件：$4.29 → ¥30.89。使用独立 `m6-jp-` 卡号，避免与30周年同号卡合并。沿用品相折价、回收、挂单、评级和图鉴排序。

按用户确认：每包5张，前4张普卡，第5张R及以上。RR1/4、AR1/5.2沿用30周年设置；SR以上按每30包平均2张模拟，再分配SR93%、SAR6%、MUR1%，即单包SR6.2%、SAR0.4%、MUR约0.066667%。第5位剩余概率为R。同类别均匀抽取，独立逐包模拟，没有盒箱保底，不声称官方概率。

卡面标记核对：R为005/011/018/031/039/043/052/056；RR为009/015/021/024/033/048/058/062；077–088为AR，089–106为SR，107–112为SAR，113为MUR。其余001–076作为普卡池。源图片有部分横向/裁切缩略图，原样显示，不生成缺失画面；部分名称保留网页英文名。

导入：`node import-m6.cjs <HTML路径> <解压后的图片目录>`。
测试：`node test-m6.cjs`、`node test-anniversary.cjs`。构建：`node build.cjs`。
