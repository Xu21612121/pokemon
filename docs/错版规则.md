# 错版规则

只对新拆出的 SAR（含同义 SIR）、UR、MUR、FUR、RGB 卡独立判定错版。每张符合条件的卡概率为 0.005% = 0.00005 = 1/20000，不是每包概率。普通、R、RR、AR、SR、金边复刻、皮卡丘、球闪、大师球及能量不参与。

抽包卡位与稀有度确定后才判定错版，不改变出货概率、盒配、卡面或价格源数据。游戏错版估值为同品相、同评级正常卡的5倍，不声称真实市场行情；评级不额外扣分。八折回收与新挂单使用此估值，已挂单的锁定报价不追溯修改。

不重新抽取旧存档的错版属性；已有错版标记保留并按5倍估值。普通旧模拟卡不再随机生成错版。

拆卡、详情、结算显示“⭐⭐⭐⭐⭐ 错版”。图鉴同一卡面仍合并展示，额外标注错版张数，收集进度不重复计数；结算中正常版与错版分别计数。跳过、连拆、存档不重新抽取属性。

验证：node test-error-variants.cjs。
