# 收藏管理更新（2026-10-29）

- 图鉴按日版30周年、M6、151、简中30周年和其他模拟卡分组。进度按当前持有的唯一卡牌版本计算，包含裸卡、评级卡、送评中与挂单卡，不包含售出或损毁卡。151三个版本独立计数；重复卡不增加进度。
- 评级仓库显示永久损毁卡面与名称，历史记录不可交易。兼容旧存档中的 lost 状态。
- 评级维持原算法：round(品相/10 − 居中偏移/20)，范围1–10。新评级保存评分依据快照；旧评级按现存字段解释并明确标注。错版不另扣分，只影响估值。这是游戏规则，不是真实评级机构标准。
- 市场支持确认撤单，无手续费，恢复上架前状态。旧挂单按有无评级分数恢复；已经到期的挂单先结算，不能撤销成交。挂单中的评级卡也保留评级估值加成。
- 卡包价格使用整数游戏售价：日版30周年25元、M6 30元、151 130元；以后新增包按类似的整5元价格设置。源报价保留用于核对，单卡价格不取整。
- 顶部规则缩短为收入、卡包配置、价格来源与评级风险提示，详细模拟配置仍保留在各卡包文档中。

验证：node test-collection.cjs；以及现有三个卡包测试。离线包用 node build.cjs 更新。
