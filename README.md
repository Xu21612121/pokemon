## 启动

最简单的方式：下载 `口袋藏馆.html`，用 Chrome、Edge 或 Safari 打开。该单文件已包含全部代码与样式，无需服务器。聊天文件预览可能禁止 JavaScript，请下载后在浏览器中打开。运行 `node build.cjs` 可在修改源码后重新生成单文件。

在仓库目录运行 `python3 -m http.server 8000 --bind 0.0.0.0`，通过本地浏览器访问端口 8000。GitHub Pages 工作流随 main 分支推送部署网站。

北京时间零点更新每日收入、商店和磨损。首次创建存档获得 1000 元；离线收入会补发。送评收费 20 元，等待一天，有 25% 损毁概率。市场挂单到期模拟成交。

存档使用浏览器 localStorage，清理浏览器数据会丢失存档。导出 JSON 可保留备份，当前尚未提供导入界面。

v0.4.0 接入用户提供的简中30周年庆典图片，共95张，包含全部30种纪念皮卡丘，但不是完整卡表。每包6张闪卡、保证1张纪念皮卡丘。其余5张从已导入的非纪念皮卡丘卡图均匀抽取，卡位随机，仅为演示抽取方案，不代表真实概率。其他语言版本仍为原有演示包。

卡片价格为随机游戏估值；卡包游戏售价25元，不是市场价。商品网页的建议零售价为18元。v0.4.1 已接入用户上传的包装原图，按原比例完整显示。离线版内嵌图片，约44MiB；在线版按需加载 assets/30th 内的图片。用户素材仅用于本项目的个人娱乐展示；不含账号或跨设备同步。
